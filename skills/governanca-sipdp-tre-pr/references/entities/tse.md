# TSE — Tribunal Superior Eleitoral

## O que é
O **TSE** (Tribunal Superior Eleitoral) é o órgão máximo da Justiça Eleitoral, estabelecendo normas nacionais aplicáveis aos tribunais regionais eleitorais (TREs).

## Atribuições Relevantes para SI/PDP
- Define Política de Segurança da Informação nacional (Res. TSE 23.763/2026)
- Define Plano Geracional de Proteção de Dados (Res. TSE 23.650/2021)
- Estabelece normas de software em nuvem (Portaria TSE 143/2026)

## Legislação de Referência
- **Resolução TSE nº 23.763/2026** — Política de Segurança da Informação (PSI) Nacional
- **Resolução TSE nº 23.650/2021** — Plano Geracional de Proteção de Dados Pessoais
