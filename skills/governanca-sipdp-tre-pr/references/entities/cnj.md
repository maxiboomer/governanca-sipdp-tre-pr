# CNJ — Conselho Nacional de Justiça

## O que é
O **CNJ** (Conselho Nacional de Justiça) é o órgão de controle do Poder Judiciário brasileiro, responsável por fiscalizar a administração e o aspecto financeiro dos tribunais.

## Atribuições Relevantes para SI/PDP
- Define estratégias nacionais de TIC para o Judiciário (Res. CNJ 370/2021)
- Define estratégia de segurança cibernética (Res. CNJ 396/2021)
- Define políticas de proteção de dados para o Judiciário (Res. CNJ 646/2025)

## Legislação de Referência
- **Resolução CNJ nº 370/2021** — Estratégia Nacional de TIC do Poder Judiciário
